# Подбор рулевых реек — «Сероба»

Сайт-помощник для подбора **б/у рулевых реек**. Заказчик — компания «Сероба» (Россия/СНГ),
пользователи сайта — **селлеры-дропшипперы**, которые подбирают рейку клиенту.

Репозиторий: https://github.com/Vyacheslav08/zero777, рабочая ветка — `main`.

---

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Весь фронтенд одним файлом: вёрстка, стили, вся логика подбора. Правки по кнопкам/дереву вопросов/ценам — сюда. |
| `api/ask.js` | ИИ-помощник. Внутри `SYSTEM_PROMPT` — полный каталог реек и правила подбора. Модель `claude-sonnet-4-6`, `max_tokens: 600`. |
| `server.js` | Node-сервер для Docker: раздаёт `index.html` и вызывает ту же функцию `api/ask.js`, что и Vercel. |
| `Dockerfile`, `docker-compose.yml` | Сборка для деплоя. Нужна переменная `ANTHROPIC_API_KEY`. |
| `vercel.json` | Запасной вариант деплоя на Vercel (сейчас основной — Docker). |

## Как устроен подбор

**Внутренние коды реек** — это язык проекта: `СК`, `3Т`, `БК`, `КР`, `В8`, `Е46+`/`Е46-`,
`E90`, `FR3+`/`FR3-`, `W164+D`/`W164-D`, `W211+D`/`W211-D` и т.д.
Суффиксы `+D` / `-D` означают «с датчиком» / «без датчика», `+` / `-` — длинная/короткая версия.

Три способа подбора, между ними переключение в шапке:

1. **По VIN** (`#pg-vin`) — VIN разбирается прямо в браузере: марка по первым 3 символам
   (`WMI`), год по 10-му символу (`YR`). Если данных не хватает — сайт задаёт уточняющие
   вопросы (дерево `TP`), пока не останется один код.
2. **Каталог** (`#pg-cat`) — выбор марки и модели из списков (`MODELS`), часто сразу даёт код.
3. **ИИ-помощник** (`#pg-ai`) — свободный чат, уходит на `POST /api/ask`.

### Данные о наличии и ценах

- **Цены** зашиты в `index.html` в константе `PR`: `d` — цена дропа, `r` — розница.
- **Наличие** тянется живьём из публичной Google-таблицы (`SHEET_ID` в `index.html`),
  выгружается как CSV через `gviz/tq?tqx=out:csv`, разбирается функцией `loadSheets()`.
- Сопоставление строк таблицы с нашими кодами — функция `getStock()`. Она сначала ищет точное
  совпадение, потом по базовому коду без суффикса. Названия в таблице не всегда совпадают с
  нашими кодами, для расхождений есть словарь `STOCK_ALIAS`.
- Кириллические двойники латинских букв (`Е90` и `E90`) сводятся к латинице через `HOMO`,
  так что код из таблицы и наш код всегда сравниваются в одном виде.

**Google-таблица — авторитетный источник по ценам, годам и наличию.** Если есть сомнения,
сверяться с ней (WebFetch по ссылке на CSV-выгрузку), а не гадать.

## Деплой

Прод — self-hosted через **Dokploy**: http://91.207.74.96:3000, приложение «Вячеслав».
Автодеплой срабатывает по push в `main`.
Сервер — **FirstVDS**: https://my.firstvds.ru

### Известная проблема

Если деплой падает с ошибкой **`Could not resolve host: github.com`** — это слетел DNS
на сервере. Лечится так:

1. Зайти в панель FirstVDS
2. Выделить сервер → кнопка **«Перезагрузка»**
3. Дождаться загрузки и заново нажать **Deploy** в Dokploy

## Как работать с этим проектом

**Заказчик — не программист.** Объяснять по-человечески, без жаргона: не «отрефакторил
хендлер», а «поправил, теперь на Passat 2008 года сайт сначала спросит про маркировку».

Типовые задачи:

- **«Правки от менеджера»** — уточнения по конкретным рейкам (цены, годы, разделение на
  варианты с датчиком и без). Правится `SYSTEM_PROMPT` в `api/ask.js` и/или логика в
  `index.html`. Важно: если правка касается и подбора, и ИИ-помощника — менять **оба места**,
  иначе кнопочный подбор и чат начнут противоречить друг другу.
- **Вопрос живого селлера** — ответить как консультант, опираясь на каталог в `SYSTEM_PROMPT`
  и таблицу. Ничего не выдумывать: если рейки нет — так и сказать.

### Коммиты

Сообщения **на русском**, в стиле существующей истории — что именно изменилось по сути:

```
W212 (задний привод): разделить на +D и -D, цены из таблицы
207 / C3 Picasso ЭУР: разделить на овальную и круглую фишку датчика
Самопроверка: исправить наличие E90, отсечь насосы, убрать противоречия
```

Пушить **сразу в `main`**, без пул-реквестов — автодеплой подхватит.
